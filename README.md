# Voiture-Intelligente-Automatique-Et-Manuel-
 Il s'agit d'une voiture intelligente basée sur le microcontrôleur Arduino, dotée de deux modes de fonctionnement : automatique et manuel. En mode automatique, la voiture évite les obstacles de manière autonome. La commande manuelle, quant à elle, s'effectue grâce à une application Android développée sur MIT App Inventor.
